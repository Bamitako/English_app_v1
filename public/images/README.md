# 単語画像の置き場所

MVPの学習画面は、各単語の写真をここから読み込みます。

## 追加のしかた

1. 無料ストック画像（Unsplash / Pexels など）を1語につき1枚用意する
2. このフォルダに `<単語id>.jpg` という名前で置く（例: `borrow.jpg`, `on-purpose.jpg`）
3. `src/data/words.ts` の該当単語に `image: '/images/borrow.jpg'` を追加する

単語idは `src/data/words.ts` の `id` フィールドです。

## 画像がまだない単語について

`image` が未設定の単語は、絵文字とシチュエーション文で代替表示されます。
学習の流れ自体は動くので、画像は1語ずつ差し替えていけます。

## 画像を選ぶときのルール

仕様どおり、以下の順で判断します。

1. 無料ストック画像で意味を表せる → その写真を使う
2. 適切な写真がない（状況・感情・抽象語） → イラストやフリー素材で代替する
3. 画像だけだと意味が曖昧 → `context` の補足文で絞る
4. それでも複数の解釈が自然 → `acceptableAnswers` に類義語を入れて答え表示時に併記する
