# 見た瞬間、英語が出てくる。

画像・状況から、日本語を介さず英単語を思い出す訓練をする学習アプリ。
「知ってる英語を、使える英語に変えたい人」向け。

## 使い方

```bash
npm install
npm run dev
```

スマホブラウザで開く前提のモバイルファースト構成。ログイン・バックエンドはなく、
学習状態は端末内（localStorage）に保存される。

## MVPの範囲

- 収録50語（動詞20 / 形容詞15 / 名詞10 / 副詞・その他5）
- ホームの4導線：ランダム学習・復習・苦手・自分の単語帳
- 1問の流れ：画像/状況を見る → 頭の中で答える →（任意で1文字ヒント）→
  答えを見る → 発音を聞く → ○ / △ / × で自己評価 → 次の問題へ
- 自由入力・4択は使わない。認識ではなく想起を鍛えるため
- 簡易復習：× はその日のうち、△ は翌日、○ は3日後
- △ / × で苦手に入り、○ を2回連続で取ると苦手から外れる
- ☆ で自分の単語帳に追加。復習 / 苦手 / 単語帳のどれからも学習できる

MVP外：ログイン、課金、ランキング、AI正誤判定、友達機能、完全な忘却曲線、
自由入力 / 4択回答。

## 構成

```
src/
  data/words.ts        収録50語
  lib/review.ts        復習スケジュールと出題プールの純粋関数
  lib/storage.ts       localStorage 読み書き
  lib/speech.ts        Web Speech API での発音再生
  hooks/useProgress.ts 学習状態
  components/          ホーム / 学習 / 一覧
```

## 画像について

Pexelsから50語ぶんを一括取得できる。無料APIキーを取って一度実行するだけ。

```bash
PEXELS_API_KEY=取得したキー npm run fetch-images
```

検索ワードは単語ごとに `src/data/words.ts` の `query` に持たせてある（`borrow` →
"handing over a pen" のように、単語そのままではなく場面で引く）。取得後は目視で
確認して、意図と違うものは `src/images/<単語id>.jpg` を直接差し替える。抽象語は
まともな写真が存在しないことが多く、その場合はファイルを置かず絵文字＋
シチュエーション文の表示に戻すほうがよい。

画像は `src/images/` に `<単語id>.jpg` の名前で置けば自動で表示される。コードの編集は
不要で、置いていない単語は絵文字で代替表示される。詳細は
[`src/images/README.md`](src/images/README.md) を参照。
